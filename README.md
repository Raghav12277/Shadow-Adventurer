Shadow Runner

A fast-paced 2D endless action-platformer built using HTML, CSS, and JavaScript.

🎮 About The Game

Shadow Runner is a dark atmospheric endless runner inspired by indie platformer games. The player controls a shadow warrior who must survive waves of enemies, collect coins, and fight increasingly dangerous monsters.

The game focuses on:

Smooth movement

Fast gameplay

Mobile-friendly controls

Atmospheric visuals

Endless progression
